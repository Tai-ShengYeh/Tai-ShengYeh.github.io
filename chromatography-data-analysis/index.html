教學重點：先看基線是否合理，再看積分面積。高擬合度不一定代表化學上正確。

基線不是裝飾線

基線定義了積分的零點。漂移被低估，面積會系統性偏高。

A = ∫[y(t) − z(t)] dt

解析度不是距離而已

峰中心的間距必須相對於峰寬評估；重疊會影響純度與定量。

Rₛ = 2(tR₂ − tR₁)/(w₁ + w₂)

面積才連到濃度

在有效線性範圍內，以校正曲線把積分面積轉為濃度。

Area = mC + b

這五題檢查你是否能把軟體輸出轉換為分析化學決策。完成後會顯示逐題回饋。

1. 基線緩慢上升，但演算法以水平線積分。最可能的影響是？

2. DAD 資料中，一個峰的前緣與後緣光譜形狀不同。優先懷疑什麼？

3. 想用最簡單的 time–signal CSV 教峰形擬合與絕對定量，優先選哪一套？

4. 對 90 張 chromatograms 完成自動處理後，下一步最合理的是？

5. 校正曲線 R² 很高，是否足以證明所有未知樣品定量可靠？

教材來源與延伸閱讀

  1. MOCCA2 documentation：原始資料支援、基線校正、adaptive peak picking、純度檢查、解卷積、compound tracking 與批次處理。
  2. cremerlab/hplc-py 與 documentation：tidy chromatogram、Chromatogram 類別、峰擬合與校正曲線。
  3. chromatoPy on PyPI：HPLC 與 GC-FID 的 Gaussian fitting、自動/手動積分與樣本群聚。
  4. Obořil J. et al. (2024). Automated processing of chromatograms. Digital Discovery, 3, 2041–2051.
