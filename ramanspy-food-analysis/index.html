Big picture

食品分析為什麼會用拉曼光譜？

拉曼光譜可以把食品中的分子振動轉成一條「指紋」。不同食品成分（脂肪、蛋白質、醣類、水、色素、添加物）會讓某些波數區域變強或變弱，因此可用於快速篩檢、摻偽判別、品質監測與微塑膠/異物鑑別。

像食品的條碼

每個樣品會得到 intensity 對 Raman shift 的曲線。峰的位置像「分子振動座標」，峰高/面積常與成分或狀態有關。

不只看單一峰

食品是複雜混合物，單一波峰常重疊。教學重點是看整條光譜的 pattern，再用 PCA / 分類模型輔助判讀。

Beginner workflow

今天只記住一條工作流

食品樣品→Raman spectrum→前處理→PCA 看群聚→解釋食品差異

載入或模擬資料

初學者先用 Notebook 產生「澱粉型/高蛋白型/摻脂型」三類模擬光譜，避免一開始卡在資料下載。

前處理

裁切有用波段、平滑雜訊、校正基線、標準化強度。這些步驟會影響後面的 PCA 與分類。

視覺化與建模

用平均光譜找可能的食品成分差異，再用 PCA score plot 看樣品是否自然分群。

PCA score plot 的直覺：每個點是一個食品樣品；距離近代表整條光譜 pattern 比較像。

RamanSPy map

RamanSPy 在流程中的位置

資料物件Spectrum、SpectralContainer、SpectralImage 用來存放單條、多條或影像型拉曼資料。
前處理 pipelinerp.preprocessing.Pipeline([...]) 可把 Cropper、SavGol、ASPLS、MinMax 等步驟串起來，讓每組資料用同一套流程。
視覺化rp.plot.spectra、rp.plot.mean_spectra 可快速畫單條、群組與平均光譜。
分析rp.analysis.decompose.PCA、NMF、KMeans、NFINDR 等可用於降維、群聚與解混；也能把資料交給 scikit-learn。
import ramanspy as rp
pipeline = rp.preprocessing.Pipeline([
    rp.preprocessing.misc.Cropper(region=(600, 1800)),
    rp.preprocessing.denoise.SavGol(window_length=9, polyorder=3),
    rp.preprocessing.baseline.ASPLS(),
    rp.preprocessing.normalise.MinMax()
])
